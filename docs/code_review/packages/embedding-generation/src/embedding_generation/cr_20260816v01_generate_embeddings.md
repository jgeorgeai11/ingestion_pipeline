        - Resolution: Deferred 2026-08-17 (re-tagged minor → suggestion for this round) to activity `docs/activities/embedding-generation/20260817v01_stream_embedding_generation.md` — a substantive refactor of the proven-live main loop, bundled there with finding 6.2 (executemany) because both restructure the same fetch-chunk-flush loop and the same test harness; it warrants its own plan, tests, and live verification rather than riding inside this fix round.
